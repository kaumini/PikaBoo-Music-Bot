## 🚀 Getting Started

Getting PikaBoo playing in your server takes under a minute.

### 1. Invite PikaBoo

Add PikaBoo to your Discord server with just a few clicks:

👉 **[Add PikaBoo to Discord](https://discord.com/oauth2/authorize?client_id=893790384415723570)**

### 2. Join a Voice Channel

Connect to any voice channel in your server.

### 3. Play Music

Use the `!play` command followed by a song name or URL:

```
!play Peekaboo Kendrick Lamar
!play https://open.spotify.com/track/...
```

That's it — PikaBoo joins your channel and starts streaming. 🎶

> 📚 Full walkthrough: **[Documentation](https://pikaboobot.netlify.app/docs)**

## 🎮 Commands

PikaBoo supports both the `!` prefix and Discord **slash commands** (`/`). The prefix is configurable per server.

### 🎵 Music

Music playback commands.

| Command | Description |
|---|---|
| `!play <song / URL>` | Play a song |
| `!pause` | Pause playback |
| `!resume` | Resume playback |
| `!skip` | Skip current song |
| `!stop` | Stop playback |
| `!volume <level>` | Adjust volume |

### 📜 Queue

Queue management commands.

| Command | Description |
|---|---|
| `!queue` | View queue |
| `!clear` | Clear the queue |
| `!shuffle` | Shuffle queue |
| `!remove <position>` | Remove song from queue |

### ℹ️ Info

Bot information commands.

| Command | Description |
|---|---|
| `!help` | Show help menu |
| `!ping` | Check bot latency |
| `!about` | Show bot information |

### 👑 Premium

Premium features and audio filters.

| Command | Description |
|---|---|
| `!24/7` | Enable 24/7 playback |
| `!bassboost` | Adjust bass levels |
| `!nightcore` | Toggle nightcore effect |
| `!8d` | Toggle 8D audio effect |
| `!karaoke` | Apply karaoke filter |
| `!filters` | Access and manage audio filters |

> 🔗 Browse the always-current list on the **[Commands page](https://pikaboobot.netlify.app/commands)**.

## 🆕 What's New

**v3.0.0 — released 20 February 2025** (major upgrade)

- **Additional sources integrated** — SoundCloud, Apple Music, Deezer and Amazon Music are now fully functional
  with PikaBoo.
- **Button support added** — music control buttons are now integrated into the embed, eliminating the need to type
  commands.
- **Lavalink issues resolved** — fixed Lavalink WebSocket errors for *"Track not found"* and *"No route found"* by
  improving route resolution and track validation.
- **System setup enhanced** — an advanced track setup system has been implemented, along with additional slash
  commands and new moderation and DJ commands.
